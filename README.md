## Banking Data Analytics Project
## Project Overview
This project focuses on analyzing banking customer data to identify important patterns, trends, and insights related to customer demographics, account information, balances, and banking behavior.

The project demonstrates how data analytics tools can be used to clean, transform, analyze, and visualize banking data to support better business decision-making.

## Project Objectives
Analyze customer banking information
Understand customer demographics and account characteristics
Identify patterns in customer balances
Analyze account distribution and customer behavior
Find relationships between important numerical features
Create meaningful data visualizations
Develop an interactive dashboard using Power BI
Generate business insights from the analyzed data

## Tech Stack

* **Python** — Data analysis & preprocessing
* **Pandas / NumPy** — Data cleaning & transformation
* **Matplotlib / Seaborn** — Exploratory visualization
* **Power BI** — Interactive dashboard & business intelligence
* **Jupyter Notebook** — Analysis workflow

## Data Preparation

* Handled missing and duplicate records
* Corrected data types
* Checked for inconsistent and invalid values
* Prepared categorical and numerical features
* Created a cleaned dataset for analysis and visualization

## 📊 Analysis

Key areas analyzed:

* Customer and account distribution
* Account types and account status
* Customer balances
* Account age
* Customer/account relationships
* Balance patterns across customer segments
* Correlations between numerical variables

## Power BI Dashboard

The project includes an interactive Power BI dashboard featuring:

* KPI cards for key banking metrics
* Account type analysis
* Account status distribution
* Balance analysis
* Customer and account insights
* Interactive filtering and visual exploration

##  Key Insights

The analysis highlights:

* Distribution of customers and accounts across account types
* Balance patterns across different customer/account segments
* Active, dormant, and closed account distribution
* High-value customer and account patterns
* Relationships between account characteristics and balances


Open the notebook in the `Python/` directory and run the analysis.

Open `PowerBI/Project.pbix` using **Power BI Desktop**.
