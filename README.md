#  Banking Data Analytics Project

##  Project Overview

This project focuses on analyzing banking customer data to identify important patterns, trends, and insights related to customer demographics, account information, balances, and banking behavior.

The project demonstrates how data analytics tools can be used to clean, transform, analyze, and visualize banking data to support better business decision-making.


##  Project Objectives

* Analyze customer banking information
* Understand customer demographics and account characteristics
* Identify patterns in customer balances
* Analyze account distribution and customer behavior
* Find relationships between important numerical features
* Create meaningful data visualizations
* Develop an interactive dashboard using Power BI
* Generate business insights from the analyzed data

##  Data Cleaning

The following preprocessing tasks were performed:

* Checked for missing values
* Identified duplicate records
* Corrected incorrect data types
* Handled inconsistent values
* Checked numerical columns for invalid values
* Prepared categorical and numerical features for analysis

---

##  Exploratory Data Analysis

The analysis explores questions such as:

* What is the distribution of customer balances?
* Which customer groups have higher balances?
* How does account age relate to balance?
* How many accounts does a typical customer have?
* What are the major customer segments?
* Which variables have strong relationships with each other?
